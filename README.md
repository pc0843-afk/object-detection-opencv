# Object Detection Using Python & OpenCV

This project performs object detection using Python and OpenCV. The system identifies and detects objects from images or webcam video in real time.

## Technologies Used
- Python
- OpenCV
- NumPy

## Features
- Real-time object detection
- Bounding box creation
- Image processing
- Webcam support

## Applications
- Security systems
- Smart surveillance
- AI vision systems
- Traffic monitoring

## Output
The system detects objects and draws rectangular bounding boxes around them.
